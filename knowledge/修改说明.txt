# knowledge 目录修改说明

## 修改时间
2026-10-28

## 修改原因
6.6 史料检索页联调时发现：`/api/rag/ask` 在网络抖动（DeepSeek API 的 HTTPS 连接被 SSL 重置/超时）时抛出 `requests.exceptions.SSLError`，未被捕获，导致整个问答接口返回 500，前端拿不到答案。

## 修改内容（rag.py）
- `deepseek_generate()` 将 `requests.post(...)` 调用包进 `try ... except requests.exceptions.RequestException`：
  - 网络失败（SSL 重置 / 连接失败 / 超时）时降级返回 `None`，不再向上抛出使接口 500；
  - 上层 `api/rag.py` 收到 `None` 后走既有兜底文案「（DeepSeek 未配置，仅展示检索到的史料）」，同时仍返回 citations + retrieved（检索结果不受影响）。
- 设计依据：与项目「LLM 可插拔、失败降级为仅展示检索结果」的既有约定一致（见 rag.py 模块 docstring / 任务 4.7 检索侧验证）。

## 验证结果
- 命令行直测 `load_index()` → 24 chunk、`retrieve` → 3 条、`deepseek_generate` → 正常生成答案。
- `POST /api/rag/ask` 实测返回 200，答案 + 4 条引用出处 + 3 条命中史料齐全；前端 /archive 页面 6 项验证全通过，无 500 / JS 报错。

## 2026-10-28 补充：新增受限联网检索 search.py（博查 Bocha + 白名单权威源）
- 新增 `search.py`：`web_search(query, count)` 调博查 Bocha Web Search API（`https://api.bochaai.com/v1/web-search`，Bearer Key 优先读 BOCHA_API_KEY、兜底读 BING_SEARCH_KEY）。
- 白名单权威源过滤：`_is_authority()` 仅放行 people.com.cn / 12371.cn / gov.cn / xinhuanet.com（及其子域），其余来源拦截，保证被兜底引用的均来自权威媒体/党史网站。
- 返回 `[{title, url, snippet}]`（经白名单过滤），供 `api/rag.py` 拼接「未核验」标注的 prompt。
- 说明：当前网络环境（无代理）对 api.bochaai.com / api.bing.com / api.tavily.com 的 HTTPS 连接均被阻断（CRYPT_E_REVOCATION_OFFLINE / SSL 握手失败），仅 DeepSeek 可达；故实际运行时联网分支命中率为 0，稳定走 `api/rag.py` 的第三级 DeepSeek 知识兜底。这不是代码/key 问题，而是网络环境限制。

## 2026-10-28 新增：红色人物史料采集（小样 10 人）

### 修改原因
把上一轮的人物名单落成可复用的史料采集流水线：权威源直采 → 结构化摘要 → 先落"待核验区"，人工复核后才进正式知识库。目的：在不违反"严禁编造史实"硬约束的前提下，把 corpus 从 5 人扩充到 10 人小样并跑通全流程。

### 新增内容
- `人物名单.csv`：10 人元数据（姓名/时期/身份/生卒/籍贯/摘要状态/资料完整度/备注）。已核验 5 人（杨靖宇、吉鸿昌、彭雪枫、杨贵、焦裕禄），待核验 5 人（赵一曼、左权、赵尚志、张自忠、白求恩）。
- `raw/authority_sources.json`：待核验 5 人的权威源（标题/URL/来源/年份），每人 3 条，全部在白名单内（人民网党史频道、中国共产党新闻网、中央党史和文献研究院、国防部、光明日报、新华网）。
- `collect_hero.py`：采集流水线脚本，四个模式
  - `--search` 博查 API 补权威源（网络不通自动跳过，不影响已有数据）
  - `--check` 白名单 + 本机可达性校验，写 `raw/采集校验报告.txt`
  - `--draft` 为待核验人物生成摘要骨架（已存在则跳过，不覆盖人工稿）
  - `--validate` 复用 `build_index.py` 解析器校验摘要格式
- `corpus_pending/`：5 份待核验摘要（赵一曼、左权、赵尚志、张自忠、白求恩），格式与 corpus 一致（`# 人物摘要` + 基本信息/生平主要经历/核心事迹/精神内涵/引用出处），每人 3 条权威出处。

### 验证结果
- `--validate`：5/5 OK，每人 4 chunks、3 出处，person 字段解析正确。
- `--check`：15 条权威源中 14 条本机可达 200，1 条 SSLError（中央党史和文献研究院旧链接，网络抖动，来源本身有效，需人工浏览器复核），非白名单 0 条。

### 合规边界（重要）
- 待核验摘要**未**写入 `corpus/`，因此**未**进入正式 FAISS 索引。人工逐条核对权威原文后，再复制到 `corpus/` 并重跑 `build_index.py`。
- 本机网络对新华网/共产党员网等不稳定，`--search` 运行时命中率可能为 0；当前权威源由受限联网检索（WebSearch 限白名单域）产出并已落盘固化，不依赖运行时网络。
