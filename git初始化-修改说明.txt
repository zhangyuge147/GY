   （总体积曾达 509MB），已从暂存区移除（git rm --cached，
   不删除本地文件）并加入忽略。

三、验证情况
----------------------------------------------------------
   - 敏感/大文件残留检查（.env、*.pth/*.pt、node_modules、
     data 目录）：暂存区零命中；
   - git check-ignore .env 确认密钥被忽略；
   - 提交后 git status：工作区干净（无未提交变更）。

四、后续使用
----------------------------------------------------------
1. 日常提交：改完代码后
   git add -A && git commit -m "说明本次修改"
   （与各目录"修改说明.txt"习惯呼应，commit 信息写明原因）
2. 回到比赛稳定版：git checkout v1.0（或切回 main 继续）
3. 推送到远程（可选，建议私有仓库）：
   git remote add origin <你的仓库地址>
   git push -u origin main --tags
4. 重要备份提醒（git 不含以下内容，需另行备份到移动硬盘/网盘）：
   - restoration/models/ 与各 weights/（模型权重，约 2GB）
   - restoration/data/（六步中间图与库里标准像，约 6.9GB）
   - evaluation/data/（评测图集）
   - uploads/、out/（用户上传与生成产物）
