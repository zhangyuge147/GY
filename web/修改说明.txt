# web 目录修改说明

## 修改时间
2026-10-28

## 修改原因
阶段 6 任务 6.3 落地：建立 Vue3 + Vite 前端工程，交付「首页（精选英雄影像轮播）」，并定下红色基因主题基调（学习强国风格）。

## 技术栈（已确认）
Vue3 + Vite + vue-router；不使用第三方 UI 库，样式全部手写（4/8px 间距体系，160/240ms 过渡，375px 起响应式）。

## 新增文件
- package.json / vite.config.js / index.html   工程配置（含开发期后端代理）
- src/main.js               应用入口
- src/router/index.js       路由（首页 + 修复对比/时空对话/史料检索占位）
- src/api/index.js          后端 API 封装（原生 fetch）
- src/styles/theme.css      设计令牌：配色 / 间距 / 字号 / 空·加载·错误态 / 骨架屏
- src/App.vue               应用壳：吸顶导航 + 布局 + 页脚免责声明
- src/views/Home.vue        首页：首屏引导 + 英雄轮播 + 三大特性
- src/components/ComingSoon.vue  占位页（6.4~6.6 落地后替换）

## 如何预览
1) 后端：python -m uvicorn main:app --app-dir server --host 0.0.0.0 --port 8000
2) 前端：cd web && npm install && npm run dev  →  浏览器打开 http://localhost:5173
